# Инструкция по использованию скрипта автоматизации кликов в VS Code

## Что было сделано:
1. Созданы все необходимые файлы для автоматизации кликов в VS Code
2. Подготовлены скрипты для установки зависимостей и запуска автоматизации
3. Созданы инструкции по использованию

## Файлы, созданные в папке `c:\vscode\auto run\`:

### 1. `simple_clicker.py`
- Упрощенный скрипт для клика по кнопке Run
- Использует файл `run.png` как эталон для поиска кнопки
- Проверяет наличие зависимостей перед запуском
- Имеет встроенные механизмы безопасности

### 2. `check_dependencies.py`
- Скрипт для проверки и установки необходимых зависимостей
- Автоматически устанавливает недостающие пакеты
- Проверяет наличие pyautogui, cv2, numpy

### 3. `setup_and_run.py` (ранее подготовлен)
- Главный скрипт, объединяющий установку зависимостей и запуск кликера
- Автоматически устанавливает pyautogui, opencv-python, pillow

### 4. `run.png` (уже был в наличии)
- Файл-шаблон для поиска кнопки Run в VS Code

## Как использовать:

### Вариант 1: Простой запуск (рекомендуется)
1. Убедитесь, что файл `run.png` находится в папке `c:\vscode\auto run\`
2. Откройте терминал в этой папке
3. Запустите команду: `python simple_clicker.py`
4. Скрипт найдет кнопку Run на экране и кликнет по ней

### Вариант 2: Полная установка
1. Запустите: `python check_dependencies.py`
2. После установки зависимостей: `python setup_and_run.py`

## Важные особенности:
- Скрипт использует механизм FAILSAFE PyAutoGUI - переместите мышь в верхний левый угол экрана для остановки
- Уровень уверенности при поиске кнопки: 70% (для надежности)
- Скрипт выводит подробную информацию о каждом действии

## Возможные проблемы:
- Если кнопка не найдена, возможно, файл `run.png` не соответствует кнопке на экране
- Если pyautogui не установлен, сначала запустите `pip install pyautogui`
- Убедитесь, что VS Code с кнопкой Run видно на экране во время работы скрипта

## Безопасность:
- Скрипт не изменяет никакие файлы, кроме чтения `run.png`
- Все действия происходят только с разрешения пользователя
- Имеется защита от случайного запуска (пауза 3 секунды перед началом)
